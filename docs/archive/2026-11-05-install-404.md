# 2026-11-05 无 Rust 安装失败排查

## 确切原因

复现 `irm https://raw.githubusercontent.com/.../install.ps1 | iex` 与本地 `scripts\install.ps1`：

- 安装脚本本身可从 raw.githubusercontent.com 下载（HTTP 200）
- 下载 Release 附件时 **HTTP 404**：`.../releases/latest/download/original-windows-x86_64.exe`
- GitHub Releases 页面显示 **There aren't any releases here**
- 远程仅有标签 `v0.3.2`，无带附件的 Release；`v0.3.3` 标签未在 origin

因此失败不是 PATH/SHA 逻辑 bug，而是 **尚未发布预编译附件**。

## 已修复 / 补充

- `install.ps1` / `install.sh`：404 快速失败，并打印中文/英文后续步骤（发 Release / 本地构建安装 / cargo）
- 新增 `scripts/install-from-local-build.ps1`、`scripts/package-local-release.ps1`
- `test-installer.ps1` 增加 exit 22 → missing-release 文案断言
- README 标明当前 404 状态与临时路径

## 用户现在该敲

本机已有 `target\release\original.exe` 时：

```powershell
cd C:\Users\PC\Documents\GitHub\original-agent
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-from-local-build.ps1
original --help
```

`irm|iex` 仍需他 **推送标签并等 Release Actions 上传附件** 后才可用。
