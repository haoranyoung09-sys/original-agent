交互启动时可从家目录选择项目，也可用 --cwd 指定目录。仓库子目录默认定位到最近的 Git 根目录。交互回合末尾列出文件工具编辑过的路径。自动验证记录命令、退出码、输出及耗时。

自动验证失败后，如果修复回合没有新的文件工具编辑，就停止自动重试。回传模型的标准输出与标准错误各保留最多 3000 个原始字符，超限时保留首尾并标明省略量。

一次性模式（-p 或位置参数）也支持 --allow-shell --auto-verify。文件工具编辑后执行一次项目验证，验证失败或找不到验证命令时进程返回非零，不额外请求模型修复。

更新：--auto-verify 可独立启用。工作区摘要也比较 Git 可见的未暂存文件和未跟踪文件；失败摘要优先保留首条识别出的错误。
