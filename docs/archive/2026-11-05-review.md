# 2026-11-05 安全与交互完善归档

## 目标与设计

保留 Rust、rustyline、Anthropic SDK 与 OpenAI 兼容客户端。参考 Pi 的简洁终端输入和 Shift+Tab 强度切换，增加轻量输入区边框，low 青色、medium 黄色、high 紫色。标准 GitHub 项目保留 Cargo.lock、源码及 vendored 依赖，排除本机构建物和个人配置。由用户提交。

## 已修复

- 路径解析不再在边界验证之前创建目录；读取不存在的路径不产生目录副作用。
- 多处 Unicode 字节截断改为按字符截断；API Key 状态不显示片段。
- read offset + limit 使用饱和加法。
- Shell 默认关闭，由 --allow-shell 显式启用；捕获输出限制 80 KB，Windows 超时请求终止进程树。
- 配置错误不再悄悄回退默认值；拒绝零 token 限制、负数/非有限价格和远程明文 HTTP。
- 禁止 OpenAI HTTP 自动重定向；不自动加载工作区 .env。
- 切换服务商覆盖旧预设价格；更新 GPT-4.1 上下文与 DeepSeek 预设。
- 增加跨平台 CI、安装脚本、许可证、贡献与安全说明。

## 验证范围与剩余限制

单元测试覆盖路径父目录、解析无副作用、配置价格及 URL 校验。真实 API 调用未测试（未使用用户密钥），GitHub CI 需要推送后执行。终端输入区是轻量框线，不是完整 Pi TUI；未实现流式输出、多行编辑、会话恢复或自动上下文压缩。Shift+Tab 当前只改变 Anthropic 运行时 effort，OpenAI 兼容请求暂未传递 reasoning_effort；GPT-4.1 本身不是可调 reasoning 模型。

安全限制详见 SECURITY.md：文件路径检查不是系统沙箱；Unix 子孙进程、TOCTOU、硬链接、明文密钥与本地历史仍需进一步加固。当前大文件读取仍可能占用大量内存。依赖漏洞审计未运行，不应宣称无漏洞。
