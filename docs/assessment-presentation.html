02 · Architecture

Layered Multi-Provider Architecture

Separation across terminal hosting, dual model protocols, workspace-gated tools, and local state.

LAYER 1 · TERMINAL

PTY Host & Classic REPL

  • terminal.rs (357L): portable-pty + vt100 host with 28-col sidebar at ≥110 columns.
  • --classic inline fallback via rustyline.
  • Shift+Tab cycles effort (low → max).
  • subscription.rs: hands off to codex, claude, or gemini CLIs.
LAYER 2 · BACKENDS

Dual-Protocol Execution

  • Anthropic: Vendored claudius 0.33.0 (Apache-2.0), patched for Windows & custom tools.
  • OpenAI-Compatible: openai_client.rs (684L) with SSE streaming + JSON fallback.
  • 429/5xx backoff retries and malformed tool JSON recovery.
  • 80% context-window compaction & tool-output deduplication.
LAYER 3 · TOOLS & STATE

Workspace & Safety Controls

  • workspace.rs: blocks .. and canonicalizes without creating missing directories.
  • 9 tools; multi_edit validates all edits atomically before write.
  • changes.rs: in-memory byte snapshots for /undo & /diff.
  • archive.rs: append-only logs with secret redaction.
Optional Worker: src/office.py (78L) converts DOCX/PPTX via stdin/stdout JSON v1 protocol with a 60s Rust deadline. No workspace .env auto-load

04 · Core Capabilities

Workflow Automation & Guardrails

Balancing autonomous coding workflows with explicit execution gates.

Shell & Execution Gating (shell.rs)

Disabled by default. Requires --allow-shell or per-command [y/N] approval. Output bounded (~80 KB head+tail) with --command-timeout (1–600s).

Auto-Verify Loop (--auto-verify)

Runs detected tests (cargo test --locked, npm test --silent, pytest, go test) without enabling arbitrary bash; feeds diagnostics back for up to 3 repair turns.

Conflict-Aware Snapshots (changes.rs)

In-memory byte snapshots power /diff and /undo (or /undo all), rejecting rollback when external edits change tracked files.

Config & Archives (config.rs, archive.rs)

Rejects remote plaintext HTTP, zero token limits, and invalid prices. Archives redact known API keys and Bearer/Authorization lines; --no-record opts out.

06 · Gaps & Risk Analysis

Identified Risks, Limitations & Debt

Four areas requiring remediation to harden security and release reliability.

1. Security & Process Boundaries

  • Path canonicalization is not an OS sandbox (TOCTOU, hard links, hostile repo files).
  • Unix timeouts kill only the immediate shell, not full process trees.
  • /login stores API keys in plaintext config.json (0o600 on Unix).

2. Release Pipeline Drift

  • release.yml asserts tag == 'v' + Cargo.toml version.
  • Cargo.toml is 0.3.9 while tag v0.3.10 exists, blocking automated builds.
  • Prebuilt binaries remain pinned at v0.3.7.

3. Provider & Code Asymmetry

  • Shift+Tab effort updates Anthropic output_config.effort only; no wire effect on OpenAI-compatible backends.
  • main.rs (1,111L) concentrates CLI, REPL, and verification logic.
  • 6 clippy warnings are not blocked by CI.

4. Maintenance & Coverage Scope

  • Vendored claudius 0.33.0 requires manual upstream patch tracking.
  • Snapshots are in-memory only; archive retention is manual.
  • No live API integration tests or scheduled cargo audit.
07 · Recommendations
